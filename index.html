新手教程

随时按 H 重新打开，按 Esc 或 H 关闭。

移动与视角

  • WASD 移动，空格 跳跃，Shift 疾跑
  • F 切换飞行：空格上升，按住 Shift 下降
  • V 第一 / 第三人称视角切换
  • 移动鼠标看向四周，Esc 释放鼠标以操作界面

挖掘与建造

  • 按住左键挖掘准星指向的方块，右键放置当前快捷栏方块
  • 右键还可与拉杆、商店等特殊方块交互，手持食物时吃东西
  • 1-9 或滚轮切换快捷栏
  • 不同工具挖掘速度不同，木镐能挖石头，石镐/铁镐能挖更硬的矿

背包与合成

  • E 打开背包：点击仓库格与快捷栏交换物品
  • 背包下半部分是合成列表，材料足够时按钮高亮，点击即可合成

生存

  • 右上/左下 HUD 显示生命与饥饿；饥饿值满时可缓慢回血
  • 夜晚会刷新僵尸等敌对生物，白天更安全；建造避难所并准备武器
  • 挖掘方块可获得金币，可在商店方块处购买物品

界面与联机

  • P 管理面板（时间/天气/传送/商店/生物），T 命令，Y 聊天，F3 碰撞箱
  • 局域网联机：房主运行 npm run server，其他玩家在连接面板填入房主 IP
