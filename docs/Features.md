## 已知限制
1. 联机时生物、时间、天气尚未服务器权威（各客户端独立）
2. 服务器不做地形生成，依赖客户端确定性种子；世界修改仅以差量保存，无持久化文件
3. 无工具耐久、无合成台/熔炉等方块实体
4. 生物无法跨越 1 格台阶（按需求禁用跳跃），可能被地形卡住
